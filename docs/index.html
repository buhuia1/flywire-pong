这是真实的果蝇大脑吗？

连接关系和胞体位置来自真实果蝇的电镜重建；神经元活动、游戏输入和动作接口是工程模型。图中没有重建神经突起，也没有实测脑活动。138,639 个模型节点中，118,086 个有胞体坐标；网页抽样显示 12,583 个。

它会一边玩一边学习吗？

当前版本只在离线阶段，用跟球规则的示范训练外部线性读出器。玩游戏时，连接图与读出器都保持冻结。这个演示不等同于活体学习、意识实验或 DishBrain 湿实验复现。

可以比较哪些对照？

安装版包含真实连接图、人工重连图、直接读取游戏状态、随机读出、断连、关闭输入、随机动作、规则跟球与手动控制。当前基准没有证明真实果蝇拓扑优于所有简单对照。源码中保留训练方法、逐条件结果和验证记录。

数据从哪里来？可以怎样使用？

连接数据来自 Shiu 等人的 FlyWire v783 整理版本；坐标与注释来自 flywire_annotations。原创代码使用 MIT 许可；FlyWire 数据及其衍生图示按 CC BY-NC 4.0 供非商业研究与教育使用。
