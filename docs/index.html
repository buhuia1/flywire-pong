03 / EXPERIMENT NOTES

THE MODEL

来源、假设与当前边界。

哪些来自真实果蝇？

神经元连接关系和胞体坐标来自 FlyWire 电镜重建。模型有 138,639 个节点，其中 118,086 个匹配到有效胞体坐标；此页面显示 12,583 个抽样胞体。活动、输入编码和游戏动作接口由程序构建。

它会边玩边学习吗？

当前版本提前使用规则跟球示范，训练外部线性读出器；游戏中所有参数冻结。它不等同于活体学习、意识实验或 DishBrain 湿实验复现。

可以比较哪些对照？

安装版包含真实图、人工重连图、直接游戏状态、随机读出、断连、关闭输入、随机动作、规则跟球和手动控制。当前结果没有证明真实果蝇拓扑优于简单对照。逐条件结果与设置保存在仓库中。
